## 2. 「官方」的判定口径

判定按**发布主体与原始发布渠道**逐条进行，满足以下全部条件才记为 `index_published`：

1. 记录登记了具体发布机构，且该机构本身是官方主体（政府部门、法定机构、公立院校、
   法定专业委员会、官方公报或官方法定文本库）。
2. URL 主机属于该机构的自有官方域，或是经该机构所在政府体系正式发布其文本的官方门户。
3. 核查状态**不含**以下出处未定标记（逐字匹配）：
   `第三方线索`、`待官方源核实`、`待核实`、`出处未核`、`已失效`、`本地接收`、`不升级`。
4. 记录没有载明链接无法取得正文。

每条已公开记录都带 `publication_basis` 字段，逐条列出上述四项的判断依据，因此分类结果可以
逐条复核，不必相信脚本结论。判定**不**只依赖域名后缀或白名单。

不通过的常见情形：

- **第三方平台**：社交媒体、新闻报道配图、商业标准索引站。这类记录只保留来源 ID、
  证据类型与限制，不公开详情。牛津学位证书的持证人 LinkedIn 帖和 GRO 核证副本的媒体配图
  都属于这一类。
- **内部补证与交接摘录**：`发布机构` 字段写的是内部补证包提供或本地交接的记录。
- **使用者提供的去标识样本**：保留来源 ID、证据类型与限制，不公开样本和本地位置。
- **出处未核、已失效或混合依据**：不按官方来源公开，不整条升级成官方证据。
- **自称官方但主机无法确认**：URL 使用裸 IP 而非机构域名，或域名与发布机构不匹配。

官方内容由其他官方渠道转载时（例如省级政府门户发布国务院公报文本），链接公开的是**转载
渠道**，记录中另有 `repost_channel_note` 写明转载关系，不冒充原始发布链接，也不据此宣称
原始渠道已核实。本次共有 9 条记录带该说明。

**更一般地说：公开链接只表示“该官方渠道发布了这段文本”。除记录明确写明为发布机构自有域名
的情形外，本次不据此宣称原始发布渠道已核实。** 每条已公开记录的 `publication_basis` 列出了
它通过的四项条件与主机名，可供逐条复核。

登记链接中若含第三方平台主机（例如商业文档托管站），该链接**不进入公开记录**，只在公开记录
中保留 `withheld_non_official_url_count` 计数，原链接留在内部审计表。若一条来源的登记链接
全部落在第三方主机上，该来源整体降为待核。

| 结果 | 数量 |
| --- | ---: |

| 其他（重定向循环、编码错误） | 2 |
| 合计去重 URL | 156 |

120 条已公开来源中，9 条至少有一个 URL 未取得正常响应。逐条结果记录在内部审计表的
`check_result` 字段（含 URL）与公开记录的 `check_status` 字段（不含 URL），检查日期为
`release_link_checked_at`。原文记录的访问日期保留在 `original_checked_at`，两者不合并。

此外，7 条记录的登记链接中含第三方平台主机，这些链接**不进入公开记录**，只在公开记录里保留
`withheld_non_official_url_count` 计数（其中 1 条已公开来源因此只公开自有官方域链接，其余
6 条本就未公开详情）。原链接留在内部审计表的 `withheld_non_official_urls` 字段。

**页面能打开不等于规则和版式已经核实。** 检查失败也不改动原来源结论，只是如实登记。

## 4. 嵌套结构与清洗

只清理来源信息和路径，不改规则或异常语义：

- `config/specs.json` 的 `generation_contract.source_binding`：内部补证包的文件哈希绑定，
  替换为 `{"publication": "withheld", "internal_file_count": N, ...}`，只保留数量。
- `config/profiles.json` 的 `source_files`：内部材料卡路径，整体移除。
- `config/sources.json` 的 `origin_files`：内部来源文件路径，移除并以
  `internal_origin_file_count` 计数代替。
- 未公开来源的 URL：不进入公开记录，只在内部审计表保留；公开记录改记不含链接的
  `check_status`。
- 文本字段中出现的项目目录前缀、内部记录名和内部包文件名，替换为占位标记。

`evidence_basis`、`anomaly_basis`、`field_provenance`、`origin_files`、`validation` 等嵌套
结构做了递归检查，公开记录的**全部字符串**都做了 URL 与内部路径扫描。
**只清理来源信息与路径，不改变规则、异常语义或待核事实。**

## 5. 保留限制

以下限制在本发布中继续成立：

- 未在来源中明示的坐标、字号、材质、防伪与编号算法一律不推断。
- 部分官方页面只支持字段内容，不支持具体版式位置；这类记录的支持范围写得比显示范围窄。
- 现行版次未确认的历史材料只作版本沿革使用，不当现行版式依据。
- 218 条有据限制仍是限制。
- 56 条未被引用的来源记录保留，不删除也不补造引用关系。
- 链接检查失败的记录保留原结论，只在检查状态字段登记失败。
