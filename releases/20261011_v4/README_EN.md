# credential_prompts_3000

**English** | [中文](README.md)

A credential-image prompt dataset for research on **detecting the origin of AI-generated text-rich images**. It is part of the Shanghai Jiao Tong University undergraduate research project “Research on Detection Algorithms for Images Generated by Mainstream Text-to-Image Models.” The dataset contains **1,000 base groups and 2,986 prompts**, covering credentials and certificates from China, the United States, and the United Kingdom.

Each `prompt` describes the document carrier, layout, field labels, and complete text to render. Personal names, credential numbers, and other personal field values are fictional, with no placeholders to fill in. The repository includes prompts, specifications, source indexes, and checking tools. No images have been generated yet.

## Dataset structure

Prompts sharing a `group_id` use the same carrier, field set, labels, and composition. Changes to field values produce three variants:

| Variant | Content | Prompts |
| --- | --- | ---: |
| `clean` | Base version with no designed anomaly | 1,000 |
| `subtle` | One subtle issue introduced into the base version | 993 |
| `strong` | Two or three issues, or one obvious issue | 993 |
| **Total** | **1,000 base groups** | **2,986** |

There are 993 complete triplets and seven UKMT mathematics competition certificate groups with only a `clean` variant. These certificates do not display scores or numbers, and the established design scope excludes anomaly variants for them. The dataset is therefore 14 prompts short of the original 3,000 target; the repository name retains that target.

All three variants are prompts for synthetic images. `clean` does not denote a real photograph, and the subtlety of the designed anomalies has not been tested on generated images.

## Categories and coverage

The dataset is organized into 29 quota units and 50 entities. A quota unit represents a credential or business category; entities distinguish document faces or more specific objects. `profile_id` identifies the layout style used.

| Dimension | Base group distribution |
| --- | --- |
| Country | China 604, United States 205, United Kingdom 191 |
| Visible text language | Chinese 604, English 396 |
| Category prefix | `C` for Chinese credentials; `E` for credentials from other countries |

See the [taxonomy](docs/taxonomy.md) for category counts, entity lists, and the definition of a style.

## Usage

Run these examples from the repository root. The tools use only the Python standard library; automated checks use Python 3.14.

Read the prompts in the first base group:

```python
import json

with open("final/prompts.jsonl", encoding="utf-8") as f:
    rows = [json.loads(line) for line in f if line.strip()]

group_id = rows[0]["group_id"]
for row in rows:
    if row["group_id"] == group_id:
        print(row["prompt_id"], row["variant"])
        prompt = row["prompt"]  # Complete prompt text
        print(prompt[:200])     # Preview the first 200 characters
```

Command-line tools are also available:

```bash
# Show the first three prompts; add --full for complete text
python src/read_example.py --data . --limit 3

# Export CSV / TXT; the output directory must not already exist
python src/export_data.py --repo . --out ./my_export

# Check data and references; write reports outside the repository
python src/validate_release.py --repo . --report-dir ../validation_out

# Rebuild public QA; output must be new and outside the repository
python src/build_qa_report.py --repo . --out ../qa_rebuilt

# Verify the file set and SHA-256 checksums
python src/verify_hashes.py --repo .
```

These tools make no network requests and do not call image models. They support reading, exporting, and checking the existing data. See [reproduction scope](docs/reproduction_scope.md) for the coverage of the historical generation workflow.

## Quality checks and known limits

The validator reports its check count and individual results, covering group and variant counts, IDs and references, prompt and visible-value hashes, human confirmation bindings, CSV consistency, and source publication conditions. Program checks, human confirmation, and image acceptance are recorded separately.

On 2026-10-11 the user explicitly confirmed all **2,986 current prompt texts**; **0** bodies remain unconfirmed. Independent clean-value confirmation remains **129 groups**. Unchanged independently confirmed templates cover **31 styles**; historical approvals remain archived. Body approval does not establish source verification or image acceptance.

The source table contains 222 records: **120** have public source indexes. The remaining **102** records retain IDs, support scope, and limits; 6 of them are marked provenance-pending. Seven dangling references affect 129 prompts across 43 base groups, and three duplicate-ID sets are registered. Preserve these exceptions when using the configuration files. Details are in [sources and limits](docs/sources_and_limits.md) and the [reference exception registry](config/known_reference_exceptions.json).

No image model has been called for this released version, so there are no measured results for image readability, OCR accuracy, visual realism, or detection difficulty.

The project team has not selected a license, and no `LICENSE` file is included. See [release integrity](docs/release_integrity.md) for file hashes and Git line-ending settings.

Values are constructed for research and have not been checked against real registries.
They are not intended for credential issuance or identity authentication.
