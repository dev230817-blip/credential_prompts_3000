# 本轮对话小样与A选择

记录依据为用户在当前对话提供的生成图与模型标注，没有访问外部来源。四类试验为爱丁堡大学学位证书、四川常住人口登记卡、香港商业登记证和美国CFP Board数字认证证书。用户提供9张，其中1张误选旧Gemini模型；有效方向比较为nano banana 2 lite四张与用户称chatgpt image 2.5 sunburst的四张。用户反馈“感觉效果不错”，认可知识引导方向，非逐项官方版式确认。

后续6张均由用户标注为nano banana 2 lite：香港商业登记证扫描/正拍/斜拍各一，CFP数字证书原生页面/屏幕正拍/屏幕斜拍各一。同组出现版式、固定文案、标识变化，并有号码金额或签署补造、缺值说明入图、条码和裁切问题。该组不满足旧的全文及版式不变要求。

使用者随后选择A：同组给定核心值相同，允许样式和固定文案不同。本版据此更改分组与target_texts语义，同时减少缺值说明和硬骨架。六张试图不作为新版4290条的出图或图片验收证据；未将附件复制到项目或公开仓库。
