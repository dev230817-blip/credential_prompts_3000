# 复现范围

公开工具支持读取成品、从 JSONL 重导出 CSV/TXT/Excel、重建 QA 报告，以及校验字段、关联、状态和文件哈希。导出文件与 QA 报告可在不读取项目内部目录的情况下重建。工具不联网、不调用图像模型。

完整历史生成流程尚未作为一个从空目录生成所有提示词的管线公开。本版由内部 20261014_v3 成品派生；内部记录的全量比较为 980 条成像段变化、2,020 条正文不变，可见值、对象、版式和画布变化均为 0。内部保护文件、试验原稿和其他过程材料不随包发布。

公开变更清单保留 980 条 ID、当前正文哈希和历史 v3 正文哈希。当前哈希和模板可重新核对；由于没有附上全部 v3 正文，单独下载本包不能重新执行完整的 v3 前后比较。该限制在 QA 报告中保留。

基础内容保留历史源提示词及其哈希，来源版本为 20261011_v4。旧公开包同时保存在仓库的另一个版本目录，6 处取值修正另有记录。来源元数据只继承旧公开表的字段，不执行新的来源网页核验。

## 文件完整性

JSONL、分类配置、成像配置及限定修正记录作为本版输入保存。CSV/TXT/Excel 由本版 export_data.py 生成；Excel 统一 XML 换行为 LF，固定使用同一 XML 写入器、ZIP 时间戳、创建平台标记、文件属性和文档修改时间，并以不压缩的 ZIP 成员保存，避免可选 lxml、操作系统、压缩库或时间变化导致不同环境出现字节差异。Excel 文件因此比普通压缩工作簿大，单元格内容保持相同。

release_manifest.json 记录除自身和 SHA256SUMS.txt 以外的包内载荷文件、字节数及 SHA-256。SHA256SUMS.txt 覆盖除自身以外的全部包内文件。校验器拒绝缺失、额外、重复和内容不符的文件。Git 使用 * -text 保留换行字节。校验命令使用 -B 避免产生字节码缓存；所有输出写在版本目录外。
