# 审核状态与使用限制

本版正文人工确认、图片生成和图片验收均为 0。状态绑定当前 sample_id 和正文 SHA-256。历史 source_prompt 已确认的标记保留为来源沿革，不能转成当前正文已确认。

本版没有发布图像、OCR 或视觉真实感评测。用户对单份纪念页试验的反馈仅作为成像描述起点；未取得新图文件、准确出图数量、模型参数及 CRD 绑定，不扩为正式图片验收。

程序检查覆盖数量、字段、组与模板关联、正文哈希、导出一致性、限定字段修正、来源 ID 解析、审核绑定和发布文件完整性。程序通过不表示证件版式、有效性、公开编号算法、来源真实性或所有待核项均已获得专业确认。

source_index.json 仅提取旧公开来源表中被本版引用的 135 个 ID；链接和支持范围沿用历史核查日期，本次未重访网页。被隐藏的链接仍隐藏，公开记录中的局部支持和限制仍保留。索引齐全不表示已经取得实物原图或具有图片再发布许可。

取值为构造的虚构值，未与实际登记系统比对；用于研究实验，不用于办理证件或身份认证。本包不含第三方图像、受控参考图、私人观察材料、人员联系方式或组员姓名。许可仍待项目组确定，未新增 LICENSE。

完整历史生成流程、内部验收与公开工具复现范围见 [reproduction_scope.md](reproduction_scope.md)。
