# 关键词与成像规则

先由国家、版本、页面选择具体模板，再读取允许的成像方式。姓名、日期、号码和机构保留为同一基础组的完整自洽内容，不拆成跨证件任意组合的词池。

实体有扫描件、正面自然拍摄、轻度斜拍三种；电子页面有电子平面呈现、屏幕正拍、屏幕斜拍三种。每组三种全部枚举，不随机缩减。实体拍摄使用浅色无文字木桌；同组正拍和斜拍保留相同背景意图。电子屏幕不添加未声明品牌或控件。

本次扫描件要求彩色平板扫描仪输出的平面文档图、均匀照明、完整证面与窄中性留白，排除桌面、手、设备、接触投影、景深和单侧自然光效果。底色、印刷颜色、材质和指定页别服从原版式，不统一改为白纸、灰度或黑白，不增加扫描污损。电子页面的平面呈现保持原规则。

卡片、册页、贴纸分别保留载体和可见页约束。画布比例与约 20° 的轻度斜拍是生成目标，未经图片测量或验收；未知坐标、字号、编号算法和防伪细节继续待核。

完整可执行描述见 [scan_rules.json](../config/scan_rules.json)、[keywords.json](../config/keywords.json) 和 [162 个模板视图](../config/imaging_templates_162.json)。配置中的用户试验反馈是历史文字记录，未附新图片，不能代表 980 条或其他载体已完成图像验证。
