# credential_prompts_3000

English | [中文](README.md)

A credential-prompt dataset for research on detecting AI-generated text-rich images, developed within the Shanghai Jiao Tong University undergraduate research project on detecting images generated by mainstream text-to-image models. Personal names and identifiers in the requested image text are constructed fictional values. No images are included.

**Current release: [20261020_v1](releases/20261020_v1/README.md)** — 1,000 base bundles and 3,000 clean prompts, covering 5 top-level categories, 29 subcategories, 50 objects and 54 layouts. Each bundle has three imaging modes. This release strengthens the flatbed-scan wording of 980 physical-document prompts.

Current-release human body approvals, generated images and accepted images are all zero. Historical source-body approval is not approval of the new imaging prompts. Machine checks do not establish source authenticity, domain correctness, OCR quality or image quality.

The [20261011_v4 historical package](releases/20261011_v4/README_EN.md) retains all original public files and checksums. It contains 2,986 clean/subtle/strong prompts. The current release derives three imaging variants from each of 1,000 clean bundles; it is not a 14-row append to the historical dataset.

Data, configuration, documentation and tools are scoped to each release. Previous root-level final/config/docs/src/tests paths now reside in releases/20261011_v4; the original Git history is preserved.
