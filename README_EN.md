# credential_prompts_3000

English | [中文](README.md)

Credential prompts for research on the origin of AI-generated text-rich images. The repository keeps its historical name. The latest release is [20261021_v1](releases/20261021_v1/README.md): **1,430 categories, 1,430 frozen content groups and 4,290 prompts**, covering 5 first-level and 40 second-level categories.

The 1,418 physical-document categories each have a scan, front photograph and oblique photograph (4,254 prompts). The 12 electronic-document categories each have a native page, front screen photograph and oblique screen photograph (36 prompts). Visible text is identical within each group. All variants are clean. Geographic counts are 1,524 China, 2,490 foreign-country and 276 international-system prompts; these are inherited coverage counts, not a 50/50 quota.

Use the [12-column CSV](releases/20261021_v1/data/credential_prompts_4290_unified.csv), [TXT](releases/20261021_v1/data/prompts.txt), [Excel](releases/20261021_v1/data/prompts_filter.xlsx), [JSONL](releases/20261021_v1/data/prompts.jsonl), or [18 examples](releases/20261021_v1/docs/examples_18.md). Capture groups are stored in extra_json.content_group_id; group_id retains its original text-tampering meaning and stays empty. Document shape and output canvas ratio are separate.

Archived releases remain unchanged: [20261020_v1](releases/20261020_v1/README.md), 3,000 prompts from 1,000 groups; [20261011_v4](releases/20261011_v4/README.md), 2,986 prompts with clean/subtle/strong content variants. Git history is preserved.

The release includes frozen inputs and offline build/export/validation tools. No new category or source research was performed. Category counts are not verified visual-template counts. Names, addresses and records are fictional. Foreign examples use English synthetic presentation and are not claimed to be official local-language versions. Newly rendered prompt bodies have not been individually approved; no new images have been generated or accepted. No document photos or user attachments are included. See [reproduction scope](releases/20261021_v1/docs/reproduction_scope.md) and [limits](releases/20261021_v1/docs/review_and_limits.md). Licensing remains undecided; no new LICENSE is added.
